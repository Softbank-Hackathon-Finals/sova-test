# 운영 이전·대응 UI 정리

2026-11-08. 기준 소스: sova-test `1237291606ea4f45be876c1a4fb8b15a691dd31c`.

## 변경 이유와 범위

기존 Sova 사이드바·워크로드 지도·전용 격리 시험을 유지하면서, 첫 화면에서 다음 작업을 찾을 수 있도록 연결 상태를 모았다. 운영 이전 담당자가 별도로 진행 중인 공유 호스트·계획·컷오버는 변경하지 않는다.

- 워크스페이스: AWS/온프렘 관측, 운영 계획 연결, 전용 격리 시험 상태와 바로가기.
- 환경 이전: 계획 연결 → 보안·데이터 판정 → 트래픽 전환 → DB 전환 → 업무 확인 → 안정화·복귀의 여섯 단계와 필요한 근거.
- 운영 계획 화면은 기존 고정 소스의 콘솔을 재사용한다. 새로운 승인 경로나 실행 권한은 추가하지 않는다.
- 관측 만료 시 준비 상태를 철회한다. 계획 조회 기록은 서버의 current 값뿐 아니라 시각도 확인하며 3분 이상 지난 기록·미래 시각은 현재 접근 상태로 표시하지 않는다.
- HTTP 200만으로 계획 결속·승인·이전 성공을 표시하지 않는다. 현재 자료 제공 계약은 계획 미연결 상태만 표현하며, 운영 판정은 네이티브 콘솔에서 확인한다.
