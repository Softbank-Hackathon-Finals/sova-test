# Sova 사이드바와 실제 관측 연결

## 원인과 변경

기존 관측 호스트는 워크로드 지도·보안 메뉴만 활성화했다. 전용 격리 시험도 지도 안에 추가돼, 메뉴는 전체 콘솔처럼 보이지만 다른 기능으로 이동할 수 없었다.

원래 Sova 셸·사이드바·스타일을 유지하고, 전용 호스트에 한해 메뉴 11개를 연결한다. 기존 제품의 승인·등록·비용·AI API를 임의로 활성화하지 않는다. 숨겨진 기존 합성 화면을 다시 노출하는 방식도 사용하지 않는다.

| 메뉴 | 연결할 자료와 동작 |
|---|---|
| 워크스페이스 | 실제 클러스터 관측과 전용 시험·제품 API 연결 상태 요약 |
| 환경 이전 | 실제 전용 시험의 승인·검증·경로 전환·복귀. 제품 운영 이전은 별도 연결 표시 |
| 워크로드 지도 | 기존 실제 자원 관측과 격리·재검증·복귀 지도·승인 기능 유지 |
| 네트워크 아틀라스 | 실제 관측한 연결·selector·소속·설정 참조 관계 |
| 보안·거버넌스 | 기존 현재 보안 설정·보존 T14 시험 패널과 전용 시험의 단계 근거 |

| 비용·예산 | 청구 API 미연결 시 금액 미확인 표시. 0원·절감률을 생성하지 않음 |

## 보안·신뢰 경계

- 기존 인증된 GET 관측·전용 시험 feed만 소비한다. 메뉴 이동은 쓰기 요청을 만들지 않는다.
- 기존 관측 모델로 스키마·revision·만료를 확인한다. 검증된 과거 시험을 현재 상태로 표시하지 않는다.
- 개인 세션이 철회되면 관측·시험 자료를 함께 철회하고, 늦게 도착한 응답을 다시 표시하지 않는다.
- 선택한 메뉴와 제목·현재 위치를 일치시킨다. 페이지 복원 시 인증된 새 조회를 사용한다.
- 기존 실행 권한·T10 승인·실행기·수집 자격을 변경하지 않는다. 메뉴 접근성과 제품 API 연결 완료는 별개다.
