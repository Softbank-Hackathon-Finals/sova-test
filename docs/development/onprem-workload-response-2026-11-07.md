# 실제 온프렘 워크로드 대응과 시각화 검증

## 목적과 기준

기존 서비스에 영향을 주지 않는 별도 무상태 시험에서 실제 격리·대체 기동·HTTP
경로 전환을 확인하고 기존 Sova 화면으로 전달한다. 합성 데이터로 운영 성공을
표시하거나 플랫폼의 승인·게이트를 통과시키는 작업이 아니다.

| 구분 | 기준 |
|---|---|
| 성공한 시험 도구 소스 | `694f7e7d37b42bd1322ac3378a6501e5badf742c` |
| 재사용한 security 소스 | `4d93137416ef947e9fc3924403c7a9580f50455c` |
| 콘솔 실행 코드 | `7208e937` — 관측 연결 도구, 기존 움직임 UI 유지 |
| 실제 런타임 이미지 | `docker.io/library/python@sha256:935c3c5b12357a7e10caa9c1e6ca5692344d97cf229832ef584be2cec9fc03df` |
| 확인한 실행 환경 | 등록된 온프렘 RKE2, 실제 arm64 노드 |

문서 커밋·시험 코드·실제 이미지 원본은 서로 다른 기준이다. 위 Python 이미지는
이번 고정 시험 런타임이며, Windows 인계의 security 서비스 이미지나 전체 취약점
0건 검증 이미지를 대신하지 않는다.

## 실제 확인 결과

- 새 namespace 세 개, 원본 API·이웃 HTTP 서비스·대체 API·확인 Pod만 사용했다.
- 원본 API의 `readOnlyRootFilesystem=false` 설정 위반을 실제 API에서 수집했다.
- 기존 보안 대응 Binding·Guard와 SQLite 효과 원장을 재사용했다.
- 격리, 대체 0→1 기동, 대체 HTTP 검증, 고정 시험 주소 전환의 네 효과가 모두
  `confirmed_applied`로 기록됐다.
- 별도 개인 API 접속 세션에서도 원본의 새 연결 거부, Green 응답, 이웃 서비스 응답,
  고정 시험 주소의 Green 응답, 확인 Pod 정상 상태를 재확인했다.
- 실제 Pod의 imageID가 위 digest와 일치했다.
- 브라우저에서 실제 UID를 가진 노드 다섯 개, 격리 노드 한 개, 전환·복구 확인을
  확인했다. JavaScript 오류와 브라우저 변경 요청은 모두 0건이었다.
- 종료 전에 관측을 만료시켰고 전용 namespace 세 개 모두 삭제 후 부재를 확인했다.

여기서 격리는 특정 독립 확인 Pod에서 원본 API로 향한 새 연결의 거부다.
모든 네트워크·기존 연결·egress 차단이나 일반 공격 탐지를 검증한 결과는 아니다.
Green으로 바뀐 주소는 전용 시험 HTTP 진입점이다. 운영 Edge·DB 이전이 아니다.

## 중단한 실험도 별도 보존

| 실행 | 결과와 수정 |
|---|---|
| 1 | JSON Patch 배열을 명령 객체로 기록하려다 전송 전에 거부. 요청 기록 형식을 수정하고 회귀 시험 추가 |
| 2 | 외부 Kubernetes 메타데이터가 명령 구조 깊이 제한에 걸림. 외부 관측 해시와 실행 명령 검증을 분리 |
| 3 | 실제 격리·대체 기동까지 확인했으나 반복 kubectl 호출로 승인 기한 만료. 이후 효과는 거부됐으며 승인 연장·재실행하지 않음 |
| 4 | 같은 기한·권한·판정 조건에서 등록된 TLS API 연결을 재사용. 네 단계 완료 |

실행마다 새 자원을 사용했고 이전 실행의 자원은 UID를 대조해 정리했다.
콘솔의 종료 시각은 JavaScript와 호환되는 밀리초 정밀도로 만료되도록 수정했다.
별도 조회 도구의 health 응답은 nonce 응답과 구분했다. 이 도구 오류를 플랫폼
실패나 격리 증거로 해석하지 않았다.

## 검증과 근거 보존

- 로컬 시험 도구·효과 원장 회귀 28개 통과.
- 콘솔 개인 조회·기존 workload 계약 시험 42개 통과.
- 실제 HTTP·API·이미지 관측, 효과 영수증, 브라우저 수신·완료·종료 확인은 별도 보존.
- Ruff와 변경 범위의 비밀 검사 통과.
- 비공개 실행 근거 루트 이름: `validation/onprem-response-20261107/`.
  성공한 실행은 `run-04/`다. `result.private.json`, `effects.private.sqlite`,
  `effects-summary.private.json`, `corroboration.private.json`,
  `browser-complete.private.json`, `browser-ended.private.json`, `actual-complete.png`를
  연결해 확인한다. UID·접속 자료·쿠키·서명 키는 공개 문서에 복사하지 않는다.

## 제품 연결에 남은 범위

이 시험은 개인에게 부여된 기존 접속 권한을 사용한다. 코드의 변경 범위 제한이
서버의 최소 권한 RBAC나 T10 제품 승인을 대신하지 않는다. 운영 연결에서는
T10 계획·승인·보류, T19 판정, T31 실행 주체·자격 발급과 실제 감사 저장 경로에
연결해야 한다. 일반 탐지 입력, 상태·DB를 가진 앱의 복구, 모든 방향의 격리,
장기간 안정성·복구 인수는 미검증이다. 이번 결과를 해당 자격의 PASS로 사용하지 않는다.
