# 사전 승인 자동 대응 개발 기록 — 2026-11-08

## 변경 이유와 경계

기존 전용 시험은 실제 발신 위반을 관측한 뒤 격리 계획 승인을 기다렸다. 긴급 차단과 복구 승인을 구분하기 위해 기존 효과 원장·어댑터를 유지한 opt-in 자동 대응 경로를 추가했다. 단순 외부 요청의 403이나 일반 침해 탐지를 입력으로 받지 않는다.

정책은 정확한 namespace·Pod·이미지·불변 설정·계획·기한과 사건 한 번에 결속한다. 위반 주입 전에 사람이 승인하고, 현재 자원과 고정 발신 tripwire를 대조한 뒤 실행한다. 실패 후 재검증·경로 전환·새 원본 복귀는 각기 별도 승인이다. 정책 철회·시험 종료는 후속 명령을 막고 소유 자원을 정리하며, 이미 전송한 명령의 취소를 보장하지 않는다.

- CI: `4737aad`의 process·container 두 작업 통과. [실행 기록](https://github.com/Softbank-Hackathon-Finals/sova-test/actions/runs/42424861207). CI는 로컬 프로토콜·소비자 경계 검증이며 클러스터 시험을 대신하지 않는다.
- 품질: Ruff, JavaScript 문법, 공개 문서 검사, gitleaks, diff 공백 검사 통과.

문서 추가 뒤 gitleaks 전체 변경 이력에서 공개 생산자 커밋 SHA를 `generic-api-key`로 분류한 1건을 발견했다. 해당 값은 이 기록과 Git에 있는 `4737aad`의 전체 SHA와 정확히 일치하며 자격증명이 아니다. 오해를 만드는 JSON 필드 이름을 바꾸고 현재 변경분을 다시 검사했다. 탐지 예외나 이력 덮어쓰기는 추가하지 않았으며, 과거 문서 커밋의 오탐 원본도 보호된 기록에 남긴다.

## 증거 위치와 미검증 사항

공개 요약: [자동 대응 시험 근거](../evidence/automatic-containment-20261108.json). 보호된 로컬 `auto-containment-20261108` 인수 디렉터리에 원본 상태·정책·서명 제어·효과 원장·요청 경로·브라우저 영상·결과·정리 기록을 보존한다. 공개 문서에 실제 접속 자격·운영 식별자·개인 경로를 싣지 않는다.

이번 결과는 고정 무상태 fixture의 자동 대응 자격이다. 일반 공격 탐지, 실제 채팅 앱의 자동 격리, 제품 T10 승인 인수, 고객 데이터·세션 복구, AWS→온프렘 앱·DB 이전은 미검증이며 완료 처리하지 않는다. 기존 수동 대응과 제품 계약은 변경하지 않았다.

## 승인 화면 문구 분리

사용자 요청에 따라 시험 자원 생성 동의와 자동 격리 정책 동의를 별도 체크박스로 분리했다. 현재 단계에 해당하는 동의만 표시하며, 자동 대응 범위에는 기존 연결 종료와 대체 실행 준비가 포함됨을 명시한다. 재검증·대체 경로 전환과 새 원본 검증·복귀는 각각 별도 문구를 사용한다. 계획·세션·승인 단계 변경 또는 상태 조회 실패 시 체크를 해제한다. 서버의 승인·서명·실행 계약은 변경하지 않는다.

격리된 브라우저 응답으로 자원 생성 동의의 요청 연결, 단계별 문구, 동의 재사용 방지, 승인할 작업이 없는 단계의 체크박스 숨김을 확인했다. 브라우저 오류는 없었으며 이 UI 검증에서는 클러스터 변경 요청을 보내지 않았다. 원본 결과는 보호된 로컬 `consent-ui-20261108` 검증 디렉터리에 보존한다. 앞선 실환경 격리 검증을 이번 UI 변경의 실환경 재시험으로 표기하지 않는다.
