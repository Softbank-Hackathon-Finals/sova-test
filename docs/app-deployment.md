2026-11-08. UI 기준은 `9297ac6`이다. 팀 저장소는 `Softbank-Hackathon-Finals/demo-app`이며, 예전 `demo-chat` URL은 같은 저장소로 연결된다. 확인한 main은 `f47d4dd247a7dde6138404b25e63f7891af61282`다.

## 팀 앱

팀 앱은 PostgreSQL·S3 호환 첨부 저장소·Secrets Manager·관리 API를 사용하는 Python 메신저다. 일반 Node 업로드와 같은 실행 설정으로 취급하지 않는다. 이미 실행 중인 AWS 출발지와 온프렘 목적지를 등록된 클러스터 UID로 대조하고, Deployment·실행 이미지·Pod UID·HTTP 응답을 콘솔에 연결한다.

- 저장소 최신 커밋과 실행 이미지의 소스 일치 여부는 별도 검증이다. 이미지가 조회됐다는 이유만으로 최신 코드 배포 완료로 표시하지 않는다.
- 관측은 90초 이내의 신원 검증된 수집만 현재 상태로 표시한다. 만료하면 Ready·Pod·HTTP 주장을 철회한다.
- 개인 세션·동일 origin을 확인한 호스트에서만 자료를 조회한다. 연결은 실행 권한을 발급하지 않는다.
- 팀 앱의 새 이미지에는 기존 `publish-image`의 고정 소스·SBOM·스캔·배포 영수증 경로를 사용한다. CI 접수·이미지 발행·실제 배포를 구분한다.
- 기존 무상태 대응 시험 도구는 고급 접기로 옮기고 실제 팀 앱 관측을 기본 지도로 사용한다. 팀 앱의 격리·이전 완료는 별도 효과 증거 없이 표시하지 않는다.

## 일반 소스 등록

ZIP과 공개 GitHub 소스를 개인 앱별 디렉터리에 보존한다. GitHub 브랜치는 전체 커밋 SHA로 먼저 고정한다. 현재 빌드 지원 범위는 정적 사이트와 main 파일·잠금 파일이 있는 Node HTTP 앱이다. 팀 Python 앱의 설정과 비밀을 자동 복제하지 않는다.

ZIP 크기·파일 수·실제 확장 크기를 제한하고 경로 탈출·링크·중복·비밀 파일·로컬 DB 파일을 거부한다. 로컬 DB 앱에는 별도 영속 저장소 프로필이 필요하다. 업로드한 Dockerfile과 설치 스크립트를 호스트에서 실행하지 않는다. Node 패키지는 고정 npm 저장소와 SHA-512 잠금 해시를 확인하고, 컨테이너 빌드에서는 네트워크·설치 스크립트를 끈다.

일반 AWS 배포 어댑터는 본인 `bravo-personal` 계정과 등록된 출발지 UID를 확인하고 새 앱 namespace만 생성한다. 이미지 digest·Pod Ready·HTTP 응답을 읽어 확인한다. 오류·재시작 후 불명확한 작업은 자동 재실행하거나 삭제하지 않는다. Cloudflare 임시 공개 주소는 사용자가 공개를 선택한 경우에만 요청하며, 영속 진입점·이전 완료를 뜻하지 않는다.

## 확인 범위

- 소스·빌드 경계·개인 API·팀 앱 관측 모델: Python 24개 통과.
- 기존 정적 자산·이전 상태 조회 호스트 회귀: Python 22개 통과.
- 기존 이전 관측 JS 모델: 8개 통과.
- 실제 팀 앱 조회: AWS 1/1, 온프렘 4/4 Ready와 양쪽 HTTP 200을 확인했다. 메시지·첨부 쓰기, 데이터 이전, 부분 격리 시험 결과가 아니다.
- 브라우저: 실제 수집 기록 재생으로 팀 앱 표시·만료 철회·모바일 배치·변경 요청 0건을 확인했다.
- 이전 TUG ZIP은 로컬 격리 빌드까지 확인했다. SQLite가 발견돼 AWS 앱 생성 전에 중단했으며 팀 앱으로 대상을 변경했다. 생성된 앱 저장용 ECR 저장소는 있으나 TUG 배포 성공으로 기록하지 않는다.
- 일반 앱의 AWS 배포·Cloudflare 공개와 팀 최신 이미지의 실제 반영은 아직 통합 인수되지 않았다. 콘솔 등록 화면만으로 이를 완료 처리하지 않는다.
