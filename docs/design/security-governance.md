# 보안·거버넌스와 워크로드 시각화

상태: 목표 계약. 공통 통제 판정·독립 보류·해제·실행 게이트의 첫 구현은 [실행 계약](../security-governance.md)에 정리한다. 기존 AWS SG 시험과 로컬 프로세스 격리 프리뷰는 통합 보안 제품의 완료가 아니다.

## 공통 통제와 실제 집행

권한·암호화·네트워크·비밀·감사·정책 준수·backup·신뢰 복구라는 보호 목적을 공통 모델로 둔다. provider 기능명과 통제 의미를 동일시하지 않는다. IAM/SCP/RBAC/NetworkPolicy 등의 차이와 적용 범위를 기록하고 실제 허용·거부 시험을 연결한다.

근거는 수집 주체·자원 revision·수집 시각·유효기간·policy revision·시험 조건과 함께 보존한다. 충족·위반·미확인·예외를 분리한다. 필수 통제의 unknown·만료는 실행을 막는다. 예외는 승인자·목적·범위·보완 통제·만료가 필요하다. 신규 승인으로 기존 보안 보류를 조용히 지우지 않는다.

## 자격 증명·테넌트 경계

제어 API는 사용자·조직·앱 인가를 수행한다. DB FORCE RLS는 방어 계층이며 공유 DB 자격을 탈취한 공격자까지 차단한다고 주장하지 않는다. 고객별 credential broker는 작업·자원·시간을 제한한 단기 역할을 실행기에만 제공한다. 앱·agent·빌드에는 관리 권한을 주지 않는다.

Secret은 값 대신 참조를 기록하고 workload별 최소 접근·회전·폐기·감사·break-glass를 시험한다. namespace·접속 역할만으로 CPU·메모리·I/O나 관리 권한까지 격리했다고 주장하지 않는다. 더 강한 요구에는 전용 노드·클러스터·DB·키·고객 경계를 후보로 비교한다.

## 동적 지도와 사고 대응

지도는 그래프에 등록된 실제 자원 식별자·상태·관계와 관측 이벤트로 생성한다. 고정 A~F 또는 게임 전용 노드를 사용하지 않는다. 서비스·DB·queue·worker·Secret·AI·진입점을 상황에 맞게 표시한다.

| 표시 | 근거 |
| --- | --- |
| 흐르는 호출 | 실제 span·응답·호출 기록 |
| 선언된 연결 | 설정·인벤토리의 관계, 실측 트래픽과 다른 선 |
| 잠재 영향 | 역방향 의존 그래프, 실제 장애로 확정하지 않음 |
| 확인된 이상 | 자원에 결합한 알림·실패와 수집 시각 |
| 격리 적용 | 승인한 효과·provider readback·차단/관리 경로 시험 |
| 미확인 | 수집 지연·만료·통신 단절·불명확한 외부 효과 |

대응은 `탐지 신호 → 증거 보존 → 영향·공유 자원 확인 → 범위와 정책 검토 → 승인된 격리 → readback → 복구/재배치 제안 → 독립 재검증`이다. 단순 노드 인접성만으로 주변 서비스를 자동 차단하지 않는다. 공유 SG·namespace 전체 정책은 영향 범위를 별도 승인한다. 관리·관측·복구 경로를 보존한다.

감염이 의심된 실행본을 그대로 목적지로 복사하지 않는다. 검증한 깨끗한 산출물, 재발급 신원, 데이터 검사와 신뢰 복구 조건으로 재배치한다. 격리 해제는 다른 권한·근거가 필요한 독립 행위다. 자격을 통과한 사전 승인 범위 밖에서는 운영자에게 제안한다.

## 감사와 운영 시험

승인·정책·외부 효과·실제 결과·복구·예외·관리자 접근을 감사 저장소에 연결한다. 서명·보존 잠금·접근 분리·키 회전과 복원 시험을 수행한다. OTel 로그만으로 불변 감사 원장을 대체하지 않는다.

교차 tenant, Secret 접근, 범위 밖 변경, 정책 만료, worker 중복, 응답 유실, 보류 우회, 감사 단절, 키 유출·폐기, 실제 데이터 유출 경로를 시험한다. 독립 리뷰와 운영 절차·사고훈련을 운영 자격의 일부로 둔다.

## 2026-11-02 여섯 영역 연결

이전 readiness 조회는 출발·목적지 양쪽 권한을 확인한 뒤 근거를 읽는다. gate 입력은 유한한 typed tuple이며 필수 의무 누락·버전/범위/revision 불일치·만료·모호한 최신 근거를 통과시키지 않는다. 기존 독립 보류·분리 해제·실행 직전 권한 확인을 유지한다.

목적지 구독 검사에서는 app DB의 제한된 migration-owner 함수를 사용해 observer에 `pg_subscription.subconninfo` 조회 권한을 주지 않는다. 함수·소유자·scope·연결 설정 변조를 실제 임시 DB에서 거부했다. 이는 기업 IAM·독립 credential broker·임의 악성 tenant 격리 전체의 운영 자격을 대체하지 않는다.
