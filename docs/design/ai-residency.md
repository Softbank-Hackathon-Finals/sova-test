# AI 리소스 관리와 데이터 레지던시

상태: 위치 admission 계약과 호출 경계를 구현했다. 실제 공급자 통합·품질·위치 검증은 남아 있다.

## 책임과 첫 범위

Sova는 관리형 AI 플랫폼 전체를 복제하지 않는다. 추론·검색·메모리·도구·로그별 의존성을 조사하고 허용된 실행 구성을 선택·검증·전환한다. 첫 자격 대상은 Bedrock 텍스트/채팅 경로와 고객 경계 내 vLLM 추론이다. 정확한 모델·배포·버전·digest·라이선스·하드웨어를 등록한 후 지원을 판정한다. Gemini Enterprise Agent Platform·Azure AI Foundry는 기능별 후속 어댑터다.

다운로드 권한이 없는 모델, 숨겨진 관리형 agent 상태, 임의 메모리 export, 모든 모델의 tool/구조화 출력 호환성, 멀티모달 실시간 무중단 전환을 가정하지 않는다.

## 위치 판정 단위

| 차원 | 포함 대상 |
| --- | --- |
| 저장 | 문서·대화·메모리·embedding·캐시·로그 |
| 처리 | 추론·embedding·검색·평가·콘텐츠 검사 |
| 전송 | 모델 endpoint·도구·외부 검색·지원 경로 |
| 복제 | backup·DR·지역 간 복제 |
| 접근 | 운영자·고객 관리자·외부 지원 주체 |
| 삭제 | 원본·파생 자료·캐시·backup의 보존 종료 |

레지던시, 접근 통제, 관할·주권 요구는 서로 다른 조건이다. 암호화·사설망은 금지된 처리 위치를 허용하지 않는다. 설정에서 확인한 사실과 provider 계약으로만 확인할 수 있는 처리를 구분하고 근거·수집 시각·유효기간을 남긴다.

## 정책·실행 경계

고객 데이터 경계에 복수 AI Gateway와 OPA 정책 엔진을 둔다. 앱은 provider 자격을 보유하지 않고 승인한 Gateway만 호출한다. 인증된 tenant/app·데이터 등급·용도·정책 revision·모델 배포·허용 위치·도구·토큰·금액 예약·기한·보존·fallback을 평가한다. 클라이언트의 등급 주장을 신뢰하지 않고 불확실하면 제한하거나 보류한다. DLP의 미탐지를 전송 허가로 쓰지 않는다.

서명된 불변 정책·routing bundle을 시험·승인·배포하고 각 인스턴스 수신과 실제 거부 동작을 검증한다. 오래된 폐기 상태의 허용 유예는 정책으로 제한한다. 원문 prompt/응답은 기본 감사 로그에서 제외한다. Sova 자신의 AI 분석도 같은 전송 정책을 적용한다.

네트워크는 DNS·redirect·도구·proxy·metadata·관리망까지 평가한다. 모델 서비스의 서버 측 web tool처럼 guest egress 외부에서 실행되는 경로도 포함한다. AI Gateway 장애 때 금지한 지역·외부 모델로 자동 fallback하지 않는다.

## 기능·품질 이전

provider/model/deployment/API·기능·처리 가능 위치 집합·보존·quota·가격·지원 종료 근거를 등록한다. 같은 배포 참조의 내부 모델 변경 가능성도 기록한다. 위치는 자원 region 하나로 추정하지 않는다. 실제 provider별 endpoint·배포 방식의 검증이 선행되어야 한다.

정제한 대표 데이터로 정확성·구조화 출력·도구 권한·안전성·지연·처리량·품질 기준을 비교한다. RAG 인덱스·embedding 모델 변경·메모리·tool 실행 상태는 별도 이전 단위다. 진행 중 agent 작업은 중복 외부 효과 없이 checkpoint·재개·취소할 수 있는 경로만 전환한다.

원문을 반출할 수 없으면 AI·샌드박스·자료·관측도 고객 경계에 배치한다. 목적지 용량·모델 권리·품질이 충족되지 않으면 변경을 보류한다. 로컬 추론이라는 이유로 자동 안전 판정을 부여하지 않는다.

## 2026-11-02 구현 경계

정확한 app/environment와 다섯 데이터 단계의 위치 규칙·목적·기능·입력 한도를 비교하는 domain model과 `AIGateway` 호출 경계를 추가했다. 서버 분류·정책/endpoint 인증 callback·요청 endpoint ID·배포 revision에 결합하고 dispatch 직전 권한·만료·변경을 재검사한다. 네트워크 결과가 불명확하면 다른 공급자에 재전송하지 않는다.

현재는 신뢰된 provider port를 주입하는 계약·거부 시험이다. 실제 공급자 위치의 증명, DLP, 호스팅 gateway, 요청별 사용량 예약·요금 상한, provider 응답의 품질 시험까지 구현한 것으로 표현하지 않는다. 상담앱의 미연결 summary는 503이며 가짜 요약을 반환하지 않는다.
