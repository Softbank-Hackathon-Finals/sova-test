# 실제 채팅 앱과 환경 이전 화면 연결

## 이번 변경

기존 Sova 외형과 자동 격리 시험을 유지하고, **환경 이전** 메뉴에 등록된 실제 채팅 앱의 출발지·목적지 배포 관측을 연결한다. 출발지 앱·연결 풀·DB와 목적지 앱·연결 풀·DB·첨부 저장소를 표시한다. 새로운 더미 계획이나 이전 성공 기록은 생성하지 않는다.

화면의 입력은 기존 `ObservedWorkloads`의 인증된 조회다. Service selector로 연결된 Pod만 집계하고 컨테이너·관련 없는 Pod를 복제본 수에 포함하지 않는다. Kubernetes Ready, 관리 경로 `/healthz`, 사용자 업무 요청 성공은 별개다. 수집 실패·90초 만료 시 현재 준비 상태와 HTTP 성공 표시를 철회한다.

`MigrationReadStatus`는 호스트가 보존한 본인 운영자 GET 결과의 시각·HTTP 상태만 반환한다. 세션·Host·Origin을 검사하고, 요청으로 계획·자격·상대 주소를 바꿀 수 없다. 읽기 중 세션이 취소되면 결과를 내보내지 않는다. 180초가 지난 기록은 과거 확인으로 표시하며, HTTP 200도 정본 계획 결속이나 변경 권한으로 승격하지 않는다. 이 접점은 네트워크 요청·서명 발급·상태 변경을 수행하지 않는다.

## 연결 계약과 남은 인수

| 영역 | 재사용할 기존 경로 | 완료 근거 |
|---|---|---|
| 계획·운영자 | T7/T9 신원·자격, T10 계획별 조회 | 현재 정본 계획·앱·양쪽 환경·프로필 일치, 본인 GET 허용 |
| 보안·데이터 준비 | T14 원문 → T10 저장 → T19 판정 | 같은 계획의 최신 양쪽 결과와 준비 보고서 |
| 앱 이동 | T10 승인 → T17 Edge | 실제 트래픽 가중치·오류율·지연 관측 |
| DB 전환 | T12 실행·T13 무결성 | 단일 writer, 마지막 변경 동기화, 영수증·시퀀스 확인 |
| 채팅 앱 | T22 원본 앱, T15/T31 검증된 목적지 이미지 | 전환 전후 메시지·첨부 보존, 신규 쓰기, WebSocket 재접속 |
| 복구 | T20/T12와 기존 승인 | 목적지 신규 데이터의 역방향 동기화, DB·Edge 복귀 확인 |
| 실제 앱 공격 대응 | 기존 보안 보류·승인·실행 원장 | 승인된 앱 Pod UID·연결 범위, 실제 차단·대체·복귀 근거 |

현재 전용 무상태 시험의 자동 격리 승인은 공유 채팅 앱에 적용하지 않는다. 채팅 앱에 연결하려면 선택한 Pod와 DB·풀러·첨부 저장소·인증 의존성을 함께 검토해야 한다. 공유 DB 역할 전체를 차단하거나 앱 모든 복제본을 무조건 종료하지 않는다. 운영 전환과 격리 시험의 실행 구간은 기존 담당자와 맞춘다.

## 2026-11-08 확인 기록

- 본인 SSO와 기존 TLS 검증 경로에서 운영 계획 GET을 다시 실행했으며 `403`이었다. 등록·승인·컷오버·권한 변경은 0건이다. 계획 참조는 보존된 이전 계획이므로 현재 정본 확인과 혼동하지 않는다.
- 실제 AWS 클러스터 신원을 대조한 출발지 채팅 Deployment 조회에서 원하는 복제본 1개, Ready 1개를 확인했다. 이는 이전 완료가 아니다.
- 기존 목적지 수집 기록에는 채팅 앱과 DB·풀러·첨부 저장소가 있다. 추가 조회 시 목적지 Tailscale 접속 장치가 Offline이고 Kubernetes 요청이 시간 초과였다. 기존 기록을 현재 PASS로 재사용하지 않는다. 사용자에게 장비 담당자 확인을 요청했다.
- 계획·권한·공용 실행 구간은 [platform PR #872](https://github.com/Softbank-Hackathon-Finals/platform/pull/872)와 [T28 인수 스레드](https://github.com/Softbank-Hackathon-Finals/platform/issues/36)에서 인수 중이다. 개인 콘솔 배포가 이 운영 인수를 대신하지 않는다.

## 검증과 기록

- 기존 대응·효과 원장 시험과 새 조회 경계 시험: **126개 통과**. 새 조회 경계 시험 17개를 포함한다.
- JavaScript 화면 모델 시험: **4개 통과**. 만료·수집 실패·관련 없는 Pod·관측 누락을 확인했다.
- 실제 수집 기록의 **브라우저 재생**: 등록 Service 7개, 화면 이동으로 변경 요청 0건, 휴대폰 가로 넘침 없음, 브라우저 오류 없음. 실환경 컷오버 시험으로 계산하지 않는다.
- 보호된 로컬 `chat-migration-20261108` 기록에 본인 GET 재확인, 메타데이터 조회, 목적지 실패, 브라우저 결과를 보존한다. 공개 문서에는 자격·실제 운영 식별자·로컬 절대경로를 넣지 않는다.

실제 채팅 앱의 자동 격리, AWS→온프렘 DB·트래픽 전환, 무중단, 전체 해피패스 완료는 이번 변경의 검증 범위가 아니다.
